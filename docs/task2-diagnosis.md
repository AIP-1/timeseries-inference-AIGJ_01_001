### 처음 실행에서 고친 것 (진단 과정 자체가 산출물)
1. [확실] **회의실 100% 결측**: 10분 센서인데 '5분 칸에 1분 값 3개 이상' 규칙을 써서 칸이 하나도 채워지지 않았다. → 장비 주기에 맞춰 최소 개수를 정함(1분 장비 3개, 2·10분 장비 1개).
2. [확실] **실습실 온도 오차가 시점이 멀수록 작아짐**(5분 0.09 → 30분 0.06℃): 2℃ 낮은 10분 센서가 칸마다 들어왔다 빠지며 공간 평균이 10분 주기 톱니가 됐다. → 장비별 5분 칸을 먼저 만들고 10분 장비는 다음 칸까지 값 유지. 고친 뒤 0.02 → 0.07 → 0.13℃로 정상.
3. 실습실 CO₂ 60분 persistence 오차도 27.8 → 24.4ppm 으로 줄었다(같은 톱니 잡음이 빠짐).

온도 60분 persistence: 사무실 0.07, 실습실 0.13, 회의실 0.15, 사무실 밖 0.27℃.

**왜 persistence 가 가장 강한가** [확실] CO₂ 는 사람 수와 환기량으로 정해지는 느린 값이라, 5분~1시간 사이에는 대부분 '지금 값'과 크게 다르지 않다. 오차는 수업·회의가 시작되거나 끝나는 몇 번의 전환 순간에 몰린다.

**왜 mean_1h 가 더 나쁜가** [확실] 1시간 평균은 평균적으로 30분 전 상태를 말한다. CO₂ 가 오르거나 내리는 동안 늘 한 박자 늦어서, 추세가 있는 구간에서는 persistence 보다 항상 나쁘다. 짧은 시점(5분)에서 차이가 가장 크다(실습실 4.5 vs 13.8).

**왜 yesterday 가 가장 나쁘고 시점과 무관한가** [가능성 높음]
- 지금 상태를 전혀 보지 않으므로 오차가 5분이든 60분이든 같다(표에서 거의 일정). 이것이 '하루 전 패턴'만으로는 부족하다는 직접 증거다.
- 월요일은 일요일(빈 방)을, 공휴일 다음 날은 빈 방을 베낀다. 시험 기간에 추석·대체공휴일·한글날이 몰려 있어 특히 불리하다.
- 같은 시각이라도 날마다 인원·환기가 달라 수준이 100ppm 단위로 바뀐다.

**공간 차이** [가능성 높음]
- 회의실이 가장 어렵다: 회의가 있는지 없는지가 날마다 다르고, 작은 방이라 사람이 들어오면 빨리 오른다. 과거 센서값에는 '곧 회의가 있다'는 정보가 없다 → 예약 정보가 가장 큰 가치를 가질 곳.
- 회의실 5분 오차(10.1)가 15분(23.9)보다 유난히 작은 것은 10분 센서의 값을 다음 칸까지 유지했기 때문이다. 5분 뒤 값이 지금 값과 같은 경우가 절반이라 5분 성적은 실제보다 좋게 보인다. 회의실은 15분 이상만 의미 있게 비교해야 한다.
- 실습실은 센서 4대 평균이라 잡음이 작고, 수업 시간이 규칙적이라 가장 쉽다.

## 5. 과제 3에 주는 시사점

1. 출력은 **변화량**으로 둔다. 모델이 persistence 에서 출발하므로 기준선보다 나빠지기 어렵다(task3 기본 설정).
2. **시각·요일 + 공휴일 표시**가 필요하다. yesterday 의 실패 원인이 요일·공휴일이다. 지금 task3 는 시각·요일만 넣었고 공휴일은 아직 없다.
3. 온도는 60분 오차가 0.07℃ 수준이라, 센서 분해능(0.1℃) 근처에서 경쟁한다. '현재값 유지보다 좋다'를 못 넘을 수 있는 공간은 사무실이다 [추측].
4. 시험 기간에 공휴일·미사용 기간이 많다. 결과를 해석할 때 '사용한 날'과 '빈 날'을 나눠 보고하는 것이 공정하다.
