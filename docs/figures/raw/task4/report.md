# 과제 4. 이상 탐지

- 시험 기간 2026-09-22 ~ 2026-10-20 에 고장 67건을 주입(공간 x 종류마다 최대 4건). 주입 기록: events.csv
- 오토인코더: 1시간 창(12칸) x CO₂·온도·습도, 학습 기간으로 학습. 임계값 = 공통 배율 x 항목별 검증 기간 99.9% 분위, 배율은 검증 기간 경보가 모든 공간 합쳐 하루 0.4회 이하가 되는 가장 작은 값(thresholds.csv)
- 규칙: 튄 값(앞뒤 칸과 크게 다름), 값 고정(같은 값이 이어짐), 새벽 기준선(02~05시 CO₂ 가 학습 기간 새벽 99% 분위 + 여유), 상승 폭(그날 새벽보다 오른 폭이 같은 요일 종류·시각의 학습 기간 99% 분위 + 여유 초과, 환기 정지·영점 틀어짐용)
- 규칙 기준도 검증 기간에서 정함: 기본값으로 하루 4.75회 울려서, 합쳐 하루 0.5회 이하가 될 때까지 가장 자주 울린 규칙부터 한 단계씩 둔하게 함(마지막 단계도 넘으면 끔). 조정 후 검증 기간 0.43회/일. 내역: rule_calibration.csv
