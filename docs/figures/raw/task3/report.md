# 과제 3. 60분 예측

- 모델: GRU(2층, 64), 과거 120분 + 하루 전·일주일 전 같은 시각의 60분 변화, 12칸 변화량 직접 출력, 모든 공간 한 모델
- 달력 입력: 시각·요일 sin/cos, 쉬는 날(주말·공휴일) 표시
- 학습 ~2026-08-25, 조기 종료는 검증 기간 ~2026-09-22, 평가는 시험 기간만(과제 2와 같은 시점)
- 장치 cpu, 변형 full, no_calendar

## 확인 기준

- 60분 CO₂: 현재값 유지 대비 21.0% 감소 → 미달 (기준 30%)
- 60분 온도: 현재값 유지 대비 -12.3% 감소 → 미달
- 시험 기간: 학습 표본·조기 종료 모두 학습/검증 구간에서만 고름(정답 60분까지 구간 안)
